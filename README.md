# Bakery Shop API

REST API для интернет-магазина выпечки с системой скидок, бонусов, управлением заказами и генерацией PDF-отчетов через fpdf2.

# Важно: Проект является демонстрационной версией. Платёжная система и production-функции исключены
# для упрощения тестирования.

## Технологический стек

- Django + Django Ninja
- PostgreSQL
- JWT аутентификация (django-ninja-jwt)
- fpdf2 (генерация PDF-отчетов)
- Docker / Docker Compose
- Redis + Celery + Celery Beat 

## Основной функционал

### Каталог товаров
- Просмотр с пагинацией (10 товаров на страницу)
- Фильтрация по категориям
- Полнотекстовый поиск


### Корзина
- Добавление/удаление товаров по slug
- Просмотр содержимого с итоговой суммой
- Полная очистка

### Заказы
- Оформление заказа из корзины с возможностью списания бонусов
- Автоматическая проверка остатков
- Автоматическая очистка корзины
- История заказов пользователя
- Поиск и фильтрация заказов
- Обновление статуса заказа (массово и индивидуально)

### Акции и скидки
- Глобальные скидки (на все товары)
- Скидки по категориям
- Автоматический пересчёт цен 
- Бонусная система (начисление процентов, списание при заказе)

### Отчеты (fpdf2)
- Генерация PDF-отчёта за последние 30 дней
- Таблица проданных товаров (название, количество, сумма)
- Общая статистика (заказы, выручка, средний чек, мин/макс заказ, потрачено бонусов)
- Топ популярных товаров
- Доход по категориям


#### Установка

Клонировать репозиторий

## Настройка секретного ключа:

В данном проекте отсутствует файл .env. Секретный ключ Django задается непосредственно в настройках проекта.
При необходимости изменить секретный ключ, его можно указать в файле settings.py в переменной SECRET_KEY.

Для генерации нового секретного ключа можно использовать следующий Python код:

* import secrets
* print(secrets.token_urlsafe(50))

Запустить контейнеры:

* docker-compose build --no-cache
* docker-compose up -d
* После успешного запуска API будет доступно по адресу: http://localhost:8000

Документация API доступна по адресу: http://localhost:8000/api/docs/
